# MT4Service — 4. Trading Operations

> Send / modify / close — with tickets as `u64` and SL/TP as plain `Option<f64>`. Order *construction* (buy/sell by side, pip SL/TP) is one layer up in [`MT4Sugar`](../MT4Sugar/MT4Sugar.Master.Overview.md).

> ⚠️ Trade calls are **not retried** — a timed-out send/close may already have executed. On error, reconcile with `opened_orders`. MQL failures surface as `MT4Error::Api { mql_code, .. }`.

---

## `order_send(request)`

```rust
pub async fn order_send(&self, request: pb::OrderSendRequest) -> Result<pb::OrderSendData, MT4Error>
```

At this layer `order_send` still takes the **raw `OrderSendRequest`** — the service doesn't shortcut it, because a market vs pending order needs different fields. Use [`MT4Sugar::buy_market`](../MT4Sugar/5.%20Order_Entry.md) etc. for side-based helpers.

**Request (key fields):** `symbol`, `operation_type` (`OrderSendOperationType` 0 Buy…5 SellStop), `volume`, `price` (pendings), `stoploss`, `takeprofit`, `slippage`, `magic_number`, `comment`. Full page: [MT4Account → order_send](../MT4Account/4.%20Trading_Operations/order_send.md).

**Returns:** `OrderSendData` — `ticket`, `volume`, `price`, `open_time`.

```rust
use metarpc_mt4::mt4_term_api as pb;

let r = svc.order_send(pb::OrderSendRequest {
    symbol: "EURUSD".into(),
    operation_type: pb::OrderSendOperationType::OcOpBuy as i32,
    volume: 0.10,
    stoploss: Some(1.0800),
    takeprofit: Some(1.0900),
    ..Default::default()
}).await?;
println!("opened #{} @ {}", r.ticket, r.price);
```

## `order_modify(ticket, stop_loss, take_profit)`

```rust
pub async fn order_modify(&self, ticket: u64, stop_loss: Option<f64>, take_profit: Option<f64>)
    -> Result<pb::OrderModifyData, MT4Error>
```

Change an order's protective levels. **`None` leaves a side untouched; `Some(0.0)` removes that stop.** (For changing a pending's trigger price, use the raw `order_modify` on `MT4Account`.)

**Returns:** `OrderModifyData` → `order_was_modified: bool`.

```rust
// Move SL to breakeven, leave TP as-is
let d = svc.order_modify(123_456, Some(1.08500), None).await?;
println!("modified: {}", d.order_was_modified);
```

## `order_close_delete(ticket, lots, slippage)`

```rust
pub async fn order_close_delete(&self, ticket: u64, lots: Option<f64>, slippage: i32)
    -> Result<pb::OrderCloseDeleteData, MT4Error>
```

Close a market order (`lots = None` closes fully, `Some(x)` partially) or delete a pending. The service passes `closing_price = None` (market).

**Returns:** `OrderCloseDeleteData` → `mode` (`OcdMarketOrder` 0 / `OcdPendingOrder` 1), `history_order_comment`.

```rust
// Full close
let d = svc.order_close_delete(123_456, None, 20).await?;
println!("mode = {:?}", d.mode);

// Partial close (0.05 lot)
svc.order_close_delete(123_456, Some(0.05), 20).await?;
```

## `order_close_by(ticket, opposite_ticket)`

```rust
pub async fn order_close_by(&self, ticket: u64, opposite_ticket: u64) -> Result<pb::OrderCloseByData, MT4Error>
```

Net two **opposite** orders on the **same symbol** against each other (saves a spread).

**Returns:** `OrderCloseByData` → `close_price`, `profit`, `close_time`.

```rust
let d = svc.order_close_by(123_456, 123_460).await?;   // buy closed by sell
println!("closed by @ {} profit {:+.2}", d.close_price, d.profit);
```
