# MT4Service — 2. Orders & History

> Open orders and closed history — with the sort enum passed directly and the payload unwrapped to a `Vec` where it's trivial.

---

## `opened_orders(sort)`

```rust
pub async fn opened_orders(&self, sort: pb::EnumOpenedOrderSortType) -> Result<Vec<pb::OpenedOrderInfo>, MT4Error>
```

Open **market + pending** orders, already unwrapped to the `Vec<OpenedOrderInfo>` (the service drops the wrapper `OpenedOrdersData` for you).

**Arg — `sort`: `EnumOpenedOrderSortType`**

| Variant | Value |
|---------|-------|
| `SortByOpenTimeAsc` | 0 |
| `SortByOpenTimeDesc` | 1 |
| `SortByOrderTicketIdAsc` | 2 |
| `SortByOrderTicketIdDesc` | 3 |

**Returns:** `Vec<OpenedOrderInfo>` — `ticket`, `symbol`, `order_type` (0 Buy…5 SellStop), `lots`, `open_price`, `stop_loss`, `take_profit`, `profit`, `swap`, `commision`, `magic_number`, `comment`, `open_time`. Full table: [MT4Account → opened_orders](../MT4Account/2.%20Orders_History/opened_orders.md).

```rust
use metarpc_mt4::mt4_term_api as pb;

let open = svc.opened_orders(pb::EnumOpenedOrderSortType::SortByOpenTimeAsc).await?;
let positions = open.iter().filter(|o| o.order_type <= 1).count();
println!("{} orders, {} positions", open.len(), positions);
```

## `opened_orders_tickets()`

```rust
pub async fn opened_orders_tickets(&self) -> Result<Vec<i32>, MT4Error>
```

Just the ticket numbers of open/pending orders — a lightweight "what's open?" check. Unwrapped to `Vec<i32>`.

```rust
let tickets = svc.opened_orders_tickets().await?;
println!("open tickets: {tickets:?}");
```

## `orders_history(sort, from, to)`

```rust
pub async fn orders_history(&self, sort: pb::EnumOrderHistorySortType, from: Option<Timestamp>, to: Option<Timestamp>)
    -> Result<pb::OrdersHistoryData, MT4Error>
```

Closed / cancelled orders over a time window. The service fills the paging defaults; you pass sort + bounds.

**Arg — `sort`: `EnumOrderHistorySortType`**

| Variant | Value |
|---------|-------|
| `HistorySortByOpenTimeAsc` | 0 |
| `HistorySortByOpenTimeDesc` | 1 |
| `HistorySortByCloseTimeAsc` | 2 |
| `HistorySortByCloseTimeDesc` | 3 |
| `HistorySortByOrderTicketIdAsc` | 4 |
| `HistorySortByOrderTicketIdDesc` | 5 |

**Args:** `from` / `to` — `Option<Timestamp>` server-time bounds (`None` = open-ended).

**Returns:** `OrdersHistoryData` → `orders_info: Vec<HistoryOrderInfo>`, `total_count`, `next_page_token`. Each `HistoryOrderInfo`: `ticket`, `symbol`, `order_type`, `lots`, `open_price`, `close_price`, `open_time`, `close_time`, `profit`, `swap`, `commision`, `magic_number`.

```rust
use metarpc_mt4::mt4_term_api as pb;
use prost_types::Timestamp;

let now = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH)?.as_secs() as i64;
let h = svc.orders_history(
    pb::EnumOrderHistorySortType::HistorySortByCloseTimeDesc,
    Some(Timestamp { seconds: now - 7 * 86_400, nanos: 0 }),
    Some(Timestamp { seconds: now, nanos: 0 }),
).await?;
let realized: f64 = h.orders_info.iter().map(|o| o.profit + o.swap + o.commision).sum();
println!("{} closed, realized {:+.2}", h.total_count, realized);
```

> **Paging:** if `next_page_token` is non-empty there are more rows — request the next page with it (raw layer).
