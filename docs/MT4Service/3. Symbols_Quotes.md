# MT4Service — 3. Symbols & Quotes

> Symbols, Market Watch, contract params and prices — passing `&str` names and slices, getting typed data back.

---

## `symbols()`

```rust
pub async fn symbols(&self) -> Result<Vec<pb::SymbolNameInfo>, MT4Error>
```

Every symbol the terminal knows, unwrapped to `Vec<SymbolNameInfo>` (`symbol_name`, `symbol_index`).

```rust
let all = svc.symbols().await?;
let eurusd = all.iter().find(|s| s.symbol_name.starts_with("EURUSD")).map(|s| s.symbol_name.clone());
println!("{} symbols, resolved {eurusd:?}", all.len());
```

---

## `symbol_select(symbol, select)`

```rust
pub async fn symbol_select(&self, symbol: &str, select: bool) -> Result<bool, MT4Error>
```

Add (`select = true`) or remove (`false`) a symbol in Market Watch. Returns the `success` bool directly.

```rust
let ok = svc.symbol_select("EURUSD", true).await?;
assert!(ok, "could not select EURUSD");
```

## `symbol_params_many(name_filter)`

```rust
pub async fn symbol_params_many(&self, name_filter: Option<&str>) -> Result<pb::SymbolParamsManyData, MT4Error>
```

Full contract params for one symbol (`Some("EURUSD")`) or all of Market Watch (`None`).

**Returns:** `SymbolParamsManyData` → `symbol_infos: Vec<SymbolParamsManyInfo>`. Key fields: `digits`, `point`, `volume_min/max/step`, `trade_tick_value`, `trade_tick_size`, `trade_contract_size`, `trade_stops_level`. Full table: [MT4Account → symbol_params_many](../MT4Account/3.%20Symbols_Quotes/symbol_params_many.md).

```rust
let s = svc.symbol_params_many(Some("EURUSD")).await?.symbol_infos.into_iter().next().unwrap();
println!("digits={} point={} step={}", s.digits, s.point, s.volume_step);
```

## `tick_value_with_size(symbols)`

```rust
pub async fn tick_value_with_size(&self, symbols: &[&str]) -> Result<pb::TickValueWithSizeData, MT4Error>
```

Tick value / size / contract size for a slice of symbols — the inputs for risk sizing.

**Returns:** `TickValueWithSizeData` → `infos: Vec<SymbolTickValueWithSizeInfo>` (`symbol_name`, `trade_tick_value`, `trade_tick_size`, `trade_contract_size`).

```rust
let d = svc.tick_value_with_size(&["EURUSD", "GBPUSD"]).await?;
for i in &d.infos { println!("{:<8} tick_value={}", i.symbol_name, i.trade_tick_value); }
```

## `quote(symbol)`

```rust
pub async fn quote(&self, symbol: &str) -> Result<pb::QuoteData, MT4Error>
```

Latest tick for one symbol — `QuoteData` (`bid`, `ask`, `high`, `low`, `date_time`).

```rust
let q = svc.quote("EURUSD").await?;
println!("spread {:.5}", q.ask - q.bid);
```

---

## `quote_many(symbols)`

```rust
pub async fn quote_many(&self, symbols: &[&str]) -> Result<pb::QuoteManyData, MT4Error>
```

Latest ticks for several symbols at once — `QuoteManyData` → `quotes: Vec<QuoteData>`. Match results by `q.symbol`.

```rust
let d = svc.quote_many(&["EURUSD", "USDJPY"]).await?;
for q in &d.quotes { println!("{:<8} {}/{}", q.symbol, q.bid, q.ask); }
```

## `quote_history(symbol, timeframe, from, to)`

```rust
pub async fn quote_history(&self, symbol: &str, timeframe: i32, from: Option<Timestamp>, to: Option<Timestamp>)
    -> Result<pb::QuoteHistoryData, MT4Error>
```

OHLC bars. `timeframe` is an `EnumQuoteHistoryTimeframe` value as `i32` — **M1 = 0 … MN1 = 8** (an ordinal, *not* MQL minutes). `from`/`to` are server-time bounds.

| M1 | M5 | M15 | M30 | H1 | H4 | D1 | W1 | MN1 |
|----|----|-----|-----|----|----|----|----|-----|
| 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

**Returns:** `QuoteHistoryData` → `historical_quotes: Vec<HistoryQuote>` (`open/high/low/close`, `time`, `tick_volume`, `spread`).

```rust
use metarpc_mt4::mt4_term_api as pb;
use prost_types::Timestamp;

let now = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH)?.as_secs() as i64;
let bars = svc.quote_history(
    "EURUSD",
    pb::EnumQuoteHistoryTimeframe::QhPeriodH1 as i32,   // = 4
    Some(Timestamp { seconds: now - 100 * 3600, nanos: 0 }),
    Some(Timestamp { seconds: now, nanos: 0 }),
).await?;
println!("{} H1 bars", bars.historical_quotes.len());
```

## `server_timezone()`

```rust
pub async fn server_timezone(&self) -> Result<pb::ServerTimezoneData, MT4Error>
```

The broker server's UTC offset — `ServerTimezoneData` (`utc_offset_seconds: Option<i32>`, `source`, `server`).

```rust
let tz = svc.server_timezone().await?;
println!("{} UTC{:+}", tz.server, tz.utc_offset_seconds.unwrap_or(0) / 3600);
```
