# MT4Service — 1. Account Information

> Account snapshot and performance statistics, with **plain arguments** instead of hand-built requests.

Each method here delegates to the matching [`MT4Account`](../MT4Account/MT4Account.Master.Overview.md) call, building the `…Request` for you. The returned payloads are the same typed `…Data` structs — see the MT4Account pages for full field tables.

```rust
use metarpc_mt4::{MT4Account, MT4Service};
let svc = MT4Service::new(MT4Account::new("mt4.mrpc.pro", 443));
svc.connect_by_server_name(12_345_678, "password", "FreshForex-Demo", None, 120).await?;
```

---

## `account_summary()`

```rust
pub async fn account_summary(&self) -> Result<pb::AccountSummaryData, MT4Error>
```

Full account snapshot — balance, equity, margin, leverage, permissions.

**Returns — `AccountSummaryData` (key fields):**

| Field | Type | Description |
|-------|------|-------------|
| `account_login` | `i64` | Login number |
| `account_balance` | `f64` | Balance (no floating P/L) |
| `account_equity` | `f64` | Balance + floating P/L |
| `account_margin` | `f64` | Margin reserved by open positions |
| `account_margin_free` | `f64` | Free margin for new positions |
| `account_margin_level` | `f64` | `equity / margin × 100` (0 if no margin used) |
| `account_leverage` | `i64` | Account leverage (e.g. 100 = 1:100) |
| `account_currency` | `String` | Deposit currency |
| `account_credit` | `f64` | Credit |
| `account_trade_allowed` | `bool` | Manual trading permitted |
| `account_trade_expert` | `bool` | EA/API trading permitted |
| `is_investor` | `bool` | Read-only (investor) login |

> Unlike MT5, MT4's `AccountSummaryData` already carries the margin fields — no separate margin call.

```rust
let a = svc.account_summary().await?;
println!("equity {:.2} {}  free margin {:.2}", a.account_equity, a.account_currency, a.account_margin_free);
```

## `trade_stats(from)`

```rust
pub async fn trade_stats(&self, from: Option<String>) -> Result<pb::StatsData, MT4Error>
```

Aggregated performance statistics. `from` is an optional **server-time** string `yyyy-MM-ddTHH:mm:ss` — `None` = since account start.

**Returns:** `StatsData` — `trades`, `profit_factor`, `sharpe_ratio`, `max_equity_drawdown_raw` / `…_relative`, `summary`, … (full table: [MT4Account → trade_stats](../MT4Account/1.%20Account_Information/trade_stats.md)).

```rust
let s = svc.trade_stats(None).await?;
println!("trades={} PF={:.2} Sharpe={:.2}", s.trades, s.profit_factor, s.sharpe_ratio);
```

---

## `trade_stats_equity_history(from, exclude_same_bars)`

```rust
pub async fn trade_stats_equity_history(&self, from: Option<String>, exclude_same_bars: Option<bool>)
    -> Result<pb::StatsWithChartsData, MT4Error>
```

Stats **plus** equity-curve points and the trade list in one call. `exclude_same_bars = Some(true)` collapses consecutive equal-equity points.

**Returns:** `StatsWithChartsData` → `stats: Option<StatsData>`, `charts`, `trades`, `open_trades`.

```rust
let d = svc.trade_stats_equity_history(None, Some(true)).await?;
println!("points={}", d.charts.len());
```

## `equity_history(from, exclude_same_bars)`

```rust
pub async fn equity_history(&self, from: Option<String>, exclude_same_bars: Option<bool>)
    -> Result<pb::EquityHistoryData, MT4Error>
```

Just the equity-curve points (no stats).

**Returns:** `EquityHistoryData` → `points: Vec<EquityPointData>` (`time`, `balance`, `equity`, `realized_pl`, `unrealized_pl`, drawdown fields).

```rust
let eq = svc.equity_history(None, None).await?;
if let Some(last) = eq.points.last() { println!("latest equity {:.2}", last.equity); }
```

## `trade_unrealized_pl(from)`

```rust
pub async fn trade_unrealized_pl(&self, from: Option<String>) -> Result<pb::TradeUnrealizedPlData, MT4Error>
```

Per-open-order unrealized-P/L **extrema** (max/min floating P/L reached and when).

**Returns:** `TradeUnrealizedPlData` → `extrema: Vec<TradeUnrealizedExtremaData>` (`ticket`, `symbol`, `max_unrealized_pl`, `min_unrealized_pl` + times).

```rust
let upl = svc.trade_unrealized_pl(None).await?;
for e in &upl.extrema {
    println!("#{} {} peak {:+.2} trough {:+.2}", e.ticket, e.symbol, e.max_unrealized_pl, e.min_unrealized_pl);
}
```
