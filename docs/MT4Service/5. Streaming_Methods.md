# MT4Service — 5. Streaming Methods

> The five server streams, renamed to `stream_*` and taking friendly args. Each returns the raw `tonic::Streaming<…Reply>`; read with `stream.message().await` and match the reply's `oneof { Data, Error }`. Drop the stream to unsubscribe.

```rust
while let Ok(Some(reply)) = stream.message().await {
    if let Some(pb::on_symbol_tick_reply::Response::Data(d)) = reply.response { /* … */ }
}
```

> `MT4Sugar` wraps the tick / profit / tickets streams into `mpsc` channels of friendly values — see [MT4Sugar 8. Watchers & Waiters](../MT4Sugar/8.%20Watchers_Waiters.md).

---

## `stream_ticks(symbols)`

```rust
pub async fn stream_ticks(&self, symbols: &[&str]) -> Result<Streaming<pb::OnSymbolTickReply>, MT4Error>
```

Live tick stream for a slice of symbols. Frame: `OnSymbolTickData.symbol_tick` → `OnSymbolMqlTickInfo` (`symbol`, `bid`, `ask`, `last`, `volume`, `time`).

```rust
use metarpc_mt4::mt4_term_api as pb;
let mut s = svc.stream_ticks(&["EURUSD", "GBPUSD"]).await?;
while let Ok(Some(r)) = s.message().await {
    if let Some(pb::on_symbol_tick_reply::Response::Data(d)) = r.response {
        if let Some(t) = d.symbol_tick { println!("{} {}/{}", t.symbol, t.bid, t.ask); }
    }
}
```

## `stream_trades()`

```rust
pub async fn stream_trades(&self) -> Result<Streaming<pb::OnTradeReply>, MT4Error>
```

Live order/trade events (new / updated / removed orders) for the account. Frame: `OnTradeData` → `event_data` (`new_orders`, `updated_orders`, `removed_orders`, `new_history_orders`) + `account_info`.

```rust
use metarpc_mt4::mt4_term_api as pb;
let mut s = svc.stream_trades().await?;
while let Ok(Some(r)) = s.message().await {
    if let Some(pb::on_trade_reply::Response::Data(d)) = r.response {
        if let Some(ev) = d.event_data {
            for o in &ev.removed_orders { println!("CLOSE #{} P/L {:+.2}", o.ticket, o.order_profit); }
        }
    }
}
```

## `stream_opened_tickets(interval_ms)`

```rust
pub async fn stream_opened_tickets(&self, interval_ms: i32) -> Result<Streaming<pb::OnOpenedOrdersTicketsReply>, MT4Error>
```

Open-order ticket list, pushed every `interval_ms`. Frame: `OnOpenedOrdersTicketsData` → `position_tickets: Vec<i32>`, `pending_order_tickets: Vec<i32>` (pre-split).

```rust
use metarpc_mt4::mt4_term_api as pb;
let mut s = svc.stream_opened_tickets(1000).await?;
if let Ok(Some(r)) = s.message().await {
    if let Some(pb::on_opened_orders_tickets_reply::Response::Data(d)) = r.response {
        println!("{} positions, {} pendings", d.position_tickets.len(), d.pending_order_tickets.len());
    }
}
```

## `stream_opened_profit(interval_ms)`

```rust
pub async fn stream_opened_profit(&self, interval_ms: i32) -> Result<Streaming<pb::OnOpenedOrdersProfitReply>, MT4Error>
```

Per-order floating profit + account snapshot, pushed every `interval_ms`. Frame: `OnOpenedOrdersProfitData` → `opened_orders_with_profit_updated`, `account_info` (`equity`, `profit`, `margin_level`).

```rust
use metarpc_mt4::mt4_term_api as pb;
let mut s = svc.stream_opened_profit(1000).await?;
while let Ok(Some(r)) = s.message().await {
    if let Some(pb::on_opened_orders_profit_reply::Response::Data(d)) = r.response {
        if let Some(a) = d.account_info { println!("equity {:.2} floating {:+.2}", a.equity, a.profit); }
    }
}
```

## `stream_connect_state()`

```rust
pub async fn stream_connect_state(&self) -> Result<Streaming<pb::OnConnectStateReply>, MT4Error>
```

Terminal connection-state events (the service passes an empty `terminal_ids`, i.e. this terminal). Frame: `ConnectStateData` → `state: String` (`"Connected"`, `"WrongPassword"`, …), `is_connected: bool`, `server`, `account`.

```rust
use metarpc_mt4::mt4_term_api as pb;
let mut s = svc.stream_connect_state().await?;
while let Ok(Some(r)) = s.message().await {
    if let Some(pb::on_connect_state_reply::Response::Data(d)) = r.response {
        println!("{}: {} (connected={})", d.account, d.state, d.is_connected);
    }
}
```
