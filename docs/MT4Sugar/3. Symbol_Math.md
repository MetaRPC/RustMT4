# MT4Sugar — 3. Symbol Math

> Point / pip / digits and the price & lot normalization you need before sending an order. All read the symbol's contract params (`symbol_params_many`) under the hood.

---

## `point(symbol)`

```rust
pub async fn point(&self, symbol: &str) -> Result<f64, MT4Error>
```

Point size (`SYMBOL_POINT`) — `0.00001` on a 5-digit FX pair.

---

## `digits(symbol)`

```rust
pub async fn digits(&self, symbol: &str) -> Result<i32, MT4Error>
```

Price decimal places (5 for EURUSD, 3 for USDJPY).

---

## `pip_size(symbol)`

```rust
pub async fn pip_size(&self, symbol: &str) -> Result<f64, MT4Error>
```

**Pip size** — `point × 10` on 3/5-digit symbols, else `point`. This is the conversion every pip-based helper uses.

```rust
let pip = sugar.pip_size("EURUSD").await?;   // 0.0001
```

---

## `pips_to_price(symbol, pips)` / `price_to_pips(symbol, price_delta)`

```rust
pub async fn pips_to_price(&self, symbol: &str, pips: f64) -> Result<f64, MT4Error>
pub async fn price_to_pips(&self, symbol: &str, price_delta: f64) -> Result<f64, MT4Error>
```

Convert between a pip distance and an absolute price distance (both directions).

```rust
let dist = sugar.pips_to_price("EURUSD", 20.0).await?;    // 0.0020
let pips = sugar.price_to_pips("EURUSD", 0.0035).await?;  // 35.0
```

---

## `normalize_lot(symbol, lot)`

```rust
pub async fn normalize_lot(&self, symbol: &str, lot: f64) -> Result<f64, MT4Error>
```

Round a lot to the symbol's `volume_step` and clamp to `[volume_min, volume_max]`. Always call this before sending a computed volume.

```rust
let lots = sugar.normalize_lot("EURUSD", 0.137).await?;   // e.g. 0.14
```

---

## `normalize_price(symbol, price)`

```rust
pub async fn normalize_price(&self, symbol: &str, price: f64) -> Result<f64, MT4Error>
```

Round a price to the symbol's `digits` — avoids "invalid price" (error 129) from float noise.

```rust
let px = sugar.normalize_price("EURUSD", 1.083456789).await?;   // 1.08346
```

---

## `tick_value(symbol)`

```rust
pub async fn tick_value(&self, symbol: &str) -> Result<f64, MT4Error>
```

Money value of one tick per lot (`SYMBOL_TRADE_TICK_VALUE`), in the account currency — the basis for [Risk Sizing](./4.%20Risk_Sizing.md).

```rust
let tv = sugar.tick_value("EURUSD").await?;
```
