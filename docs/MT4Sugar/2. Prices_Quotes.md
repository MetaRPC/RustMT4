# MT4Sugar — 2. Prices & Quotes

> Live prices as the friendly [`Quote`](https://github.com/MetaRPC/RustMT4/blob/main/src/models.rs) DTO, plus mid/spread helpers, a "wait for a usable quote" guard, and bar history.

**`Quote`** = `{ symbol, bid, ask, time, time_msc, high, low }` with `.spread()` and `.is_usable()` helpers.

---

## `last_quote(symbol)`

```rust
pub async fn last_quote(&self, symbol: &str) -> Result<Quote, MT4Error>
```

Latest [`Quote`] for one symbol (wraps `MT4Service::quote`).

```rust
let q = sugar.last_quote("EURUSD").await?;
println!("{} {}/{} spread {:.5}", q.symbol, q.bid, q.ask, q.spread());
```

---

## `quotes(symbols)`

```rust
pub async fn quotes(&self, symbols: &[&str]) -> Result<Vec<Quote>, MT4Error>
```

Latest quotes for several symbols as `Vec<Quote>`.

```rust
for q in sugar.quotes(&["EURUSD", "GBPUSD"]).await? {
    println!("{:<8} {}", q.symbol, (q.bid + q.ask) / 2.0);
}
```

## `mid_price(symbol)`

```rust
pub async fn mid_price(&self, symbol: &str) -> Result<f64, MT4Error>
```

`(bid + ask) / 2` in one call.

```rust
let mid = sugar.mid_price("EURUSD").await?;
```

---

## `spread_pips(symbol)`

```rust
pub async fn spread_pips(&self, symbol: &str) -> Result<f64, MT4Error>
```

Current spread expressed in **pips** (uses the symbol's `pip_size`). Returns `0.0` if pip size is unknown.

```rust
if sugar.spread_pips("EURUSD").await? > 2.0 { /* skip entry */ }
```

---

## `ensure_symbol(symbol, wait)`

```rust
pub async fn ensure_symbol(&self, symbol: &str, wait: Duration) -> Result<Quote, MT4Error>
```

Select the symbol in Market Watch, then **poll until it publishes a usable two-sided quote** (`bid > 0 && ask > bid`) or `wait` elapses. The must-have call before trading a fresh symbol — demo feeds often send `bid == ask` or zeros at first.

```rust
use std::time::Duration;
let q = sugar.ensure_symbol("EURUSD", Duration::from_secs(10)).await?;
println!("ready: {}/{}", q.bid, q.ask);
```

## `bars(symbol, timeframe, count)`

```rust
pub async fn bars(&self, symbol: &str, timeframe: i32, count: usize) -> Result<Vec<Bar>, MT4Error>
```

The newest `count` bars of `timeframe`, **oldest first**. `timeframe` is an `EnumQuoteHistoryTimeframe` value (M1 = 0 … MN1 = 8). Returns `Vec<Bar>` = `{ time, open, high, low, close, tick_volume, real_volume, spread }`.

```rust
use metarpc_mt4::mt4_term_api as pb;

let bars = sugar.bars("EURUSD", pb::EnumQuoteHistoryTimeframe::QhPeriodH1 as i32, 100).await?;
let hi = bars.iter().map(|b| b.high).fold(f64::MIN, f64::max);
println!("{} bars, range high {hi}", bars.len());
```

> ⚠️ `timeframe` is an **ordinal 0–8**, not MQL minutes — `H1` is `4`.
