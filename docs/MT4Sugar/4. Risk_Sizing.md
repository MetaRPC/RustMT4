# MT4Sugar — 4. Risk Sizing

> Turn a stop distance into cash risk, and a cash-risk budget into a normalized lot size. Both use the symbol's pip value per lot (`trade_tick_value × pip_size / trade_tick_size`).

---

## `calc_cash_risk(symbol, lots, sl_pips)`

```rust
pub async fn calc_cash_risk(&self, symbol: &str, lots: f64, sl_pips: f64) -> Result<f64, MT4Error>
```

How much deposit currency you'd lose if `lots` is stopped out `sl_pips` away.

`cash = lots × sl_pips × pip_value_per_lot`

```rust
let risk = sugar.calc_cash_risk("EURUSD", 0.10, 20.0).await?;
println!("risking {risk:.2} on 0.10 lot / 20 pips");
```

---

## `calc_lot_by_risk(symbol, risk_cash, sl_pips)`

```rust
pub async fn calc_lot_by_risk(&self, symbol: &str, risk_cash: f64, sl_pips: f64) -> Result<f64, MT4Error>
```

The inverse: the **normalized** lot size that risks `risk_cash` over an `sl_pips` stop.

`lots = risk_cash / (sl_pips × pip_value_per_lot)` → rounded to `volume_step`, clamped to `[min, max]`.

Guards: if `sl_pips <= 0` or pip value is unknown, it returns the symbol's minimum normalized lot rather than erroring.

```rust
// Risk 1% of balance on a 20-pip stop
let bal = sugar.get_account_info().await?.balance;
let lots = sugar.calc_lot_by_risk("EURUSD", bal * 0.01, 20.0).await?;
let r = sugar.buy_market("EURUSD", lots, None, None).await?;
println!("opened #{} with {lots} lot", r.ticket);
```

---

> **Typical flow:** pick a stop in pips → `calc_lot_by_risk` for the volume → `buy_market` / `sell_market` → set SL/TP with [`modify_sl_tp_by_pips`](./6.%20Order_Management.md). The [`Strategies`](../Strategies/Strategies.Master.Overview.md) orchestrators chain exactly this.
