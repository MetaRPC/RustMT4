# MT4Sugar — 7. Trailing & Breakeven

> Two one-shot stop-management primitives. Each inspects the position once, moves the stop **only in the safe direction**, and returns whether it moved. Call them on a timer to keep them active — they hold no background state themselves.

---

## `auto_breakeven(ticket, trigger_pips, plus_pips)`

```rust
pub async fn auto_breakeven(&self, ticket: u64, trigger_pips: f64, plus_pips: f64) -> Result<bool, MT4Error>
```

Once the position is at least `trigger_pips` in profit, move its stop to `entry ± plus_pips` (a small lock-in above/below the open price). **Never loosens** an existing stop. Returns `true` if the stop was moved this call.

* `trigger_pips` — how much profit before breakeven arms.
* `plus_pips` — where the new stop sits relative to entry (`0` = exact breakeven, positive = locked profit).

```rust
// Arm at +10 pips, lock +2 pips of profit
let moved = sugar.auto_breakeven(123_456, 10.0, 2.0).await?;
if moved { println!("stop moved to breakeven+2"); }
```

---

## `trail_stop(ticket, distance_pips)`

```rust
pub async fn trail_stop(&self, ticket: u64, distance_pips: f64) -> Result<bool, MT4Error>
```

Ratchet the stop to `distance_pips` behind the current price, **only ever tightening**. Returns `true` if the stop was moved this call.

```rust
let moved = sugar.trail_stop(123_456, 15.0).await?;   // trail 15 pips behind
```

---

## Running them continuously

Both are **one-shot** — drive them from a loop:

```rust
use std::time::Duration;

loop {
    if sugar.find_ticket(123_456).await?.is_none() { break; }   // closed → stop
    sugar.auto_breakeven(123_456, 10.0, 2.0).await?;
    sugar.trail_stop(123_456, 15.0).await?;
    tokio::time::sleep(Duration::from_secs(2)).await;
}
```

> This is exactly what the [`Strategies`](../Strategies/Strategies.Master.Overview.md) `manage()` worker does — with an activation gate so trailing starts only after a configured profit.

---

## ⚠️ Pitfalls

* **Direction-safe by design.** Neither will ever widen risk; a call that would loosen the stop returns `false` and does nothing.
* **Needs a live quote.** Both read `last_quote`; on a dead feed they'll error — pair with [`ensure_symbol`](./2.%20Prices_Quotes.md).
* **Respect stops level.** A trail closer than `trade_stops_level` is rejected by the broker (130).
