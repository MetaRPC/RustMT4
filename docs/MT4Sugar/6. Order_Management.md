# MT4Sugar — 6. Order Management

> Close, partially close, net, bulk-close, cancel pendings, and move SL/TP by price or by pips.

**`CloseResult`** = `{ mode, history_order_comment }` — `mode = 0` a market order was closed, `1` a pending was deleted.

---

## `close(ticket, lots)`

```rust
pub async fn close(&self, ticket: u64, lots: Option<f64>) -> Result<CloseResult, MT4Error>
```

Close a market order fully (`lots = None`) or partially (`Some(x)`), or delete a pending. Uses the default slippage.

```rust
sugar.close(123_456, None).await?;          // full close
```

---

## `close_partial(ticket, lots)`

```rust
pub async fn close_partial(&self, ticket: u64, lots: f64) -> Result<CloseResult, MT4Error>
```

Scale out part of a market order — a shorthand for `close(ticket, Some(lots))`.

```rust
sugar.close_partial(123_456, 0.05).await?;  // close 0.05 lot of it
```

---

## `close_by(ticket, opposite_ticket)`

```rust
pub async fn close_by(&self, ticket: u64, opposite_ticket: u64) -> Result<pb::OrderCloseByData, MT4Error>
```

Net two **opposite** orders on the **same symbol** against each other (saves a spread). Returns the raw `OrderCloseByData` (`close_price`, `profit`, `close_time`).

```rust
let d = sugar.close_by(123_456, 123_460).await?;
println!("netted, profit {:+.2}", d.profit);
```

---

## `close_all(symbol)`

```rust
pub async fn close_all(&self, symbol: Option<&str>) -> Result<usize, MT4Error>
```

Close every open **market** order (all symbols if `None`, or just one). Returns how many closed.

```rust
let n = sugar.close_all(Some("EURUSD")).await?;
println!("closed {n} EURUSD positions");
```

---

## `cancel_pendings(symbol)`

```rust
pub async fn cancel_pendings(&self, symbol: Option<&str>) -> Result<usize, MT4Error>
```

Delete every **pending** order (all symbols if `None`, or just one). Returns how many deleted.

```rust
let n = sugar.cancel_pendings(None).await?;
```

---

## `modify_sl_tp_by_price(ticket, sl, tp)`

```rust
pub async fn modify_sl_tp_by_price(&self, ticket: u64, sl: Option<f64>, tp: Option<f64>) -> Result<(), MT4Error>
```

Set SL/TP to **absolute prices**. `None` leaves a side untouched.

```rust
sugar.modify_sl_tp_by_price(123_456, Some(1.08500), None).await?;  // SL only
```

---

## `modify_sl_tp_by_pips(ticket, sl_pips, tp_pips)`

```rust
pub async fn modify_sl_tp_by_pips(&self, ticket: u64, sl_pips: Option<f64>, tp_pips: Option<f64>) -> Result<(), MT4Error>
```

Set SL/TP as **pip distances from the order's open price**, direction-aware (handles buy vs sell sign for you). Looks up the order to read its side and open price.

```rust
// 20-pip stop, 40-pip target, regardless of side
sugar.modify_sl_tp_by_pips(123_456, Some(20.0), Some(40.0)).await?;
```

---

## ⚠️ Pitfalls

* **"No changes" (error 1).** Re-sending identical levels is rejected — track current SL/TP.
* **Order must be open.** `modify_sl_tp_by_pips` errors if the ticket isn't currently open.
* **Bulk ops are best-effort.** `close_all` / `cancel_pendings` count successes; a single failure doesn't abort the rest.
