# MT4Sugar — 5. Order Entry

> Open positions and pendings by **side + lots** — no hand-built `OrderSendRequest`. Each helper stamps the default magic / slippage / comment (from [`set_defaults`](./1.%20Connection_Defaults.md)) and returns an [`OrderResult`](https://github.com/MetaRPC/RustMT4/blob/main/src/models.rs).

**`OrderResult`** = `{ ticket, error_code, price, lots, open_time, message }`. On success `error_code = 0`; MQL failures come back as `MT4Error::TradeError(code, msg)`.

> `sl` / `tp` are **absolute prices** (`Option<f64>`). Convert pip distances with [`pips_to_price`](./3.%20Symbol_Math.md) first, or open without stops and set them with [`modify_sl_tp_by_pips`](./6.%20Order_Management.md).

---

## `place_order(req)`

```rust
pub async fn place_order(&self, req: OrderRequest) -> Result<OrderResult, MT4Error>
```

The low-level entry point the others build on — send a fully-built [`OrderRequest`]. Maps a non-zero `mql_code` to `MT4Error::TradeError`. Use the side helpers below unless you need full control.

---

## Market orders

```rust
pub async fn buy_market(&self, symbol: &str, lots: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
pub async fn sell_market(&self, symbol: &str, lots: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
```

Open at the current price.

```rust
let r = sugar.buy_market("EURUSD", 0.10, Some(1.0800), Some(1.0900)).await?;
println!("opened #{} @ {}", r.ticket, r.price);
```

## Pending orders

```rust
pub async fn buy_limit(&self, symbol: &str, lots: f64, price: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
pub async fn sell_limit(&self, symbol: &str, lots: f64, price: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
pub async fn buy_stop (&self, symbol: &str, lots: f64, price: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
pub async fn sell_stop(&self, symbol: &str, lots: f64, price: f64, sl: Option<f64>, tp: Option<f64>) -> Result<OrderResult, MT4Error>
```

Place a pending at `price`. Rule of thumb:

| Helper | Fires when price… | Typical use |
|--------|-------------------|-------------|
| `buy_limit` | drops to `price` | buy the dip |
| `sell_limit` | rises to `price` | sell the rally |
| `buy_stop` | rises through `price` | breakout long |
| `sell_stop` | drops through `price` | breakout short |

```rust
// Breakout long 15 pips above the current ask
let ask = sugar.last_quote("EURUSD").await?.ask;
let trigger = ask + sugar.pips_to_price("EURUSD", 15.0).await?;
let r = sugar.buy_stop("EURUSD", 0.10, trigger, None, None).await?;
println!("pending #{}", r.ticket);
```

## ⚠️ Pitfalls

* **Normalize first.** Pass a lot through [`normalize_lot`](./3.%20Symbol_Math.md) and prices through [`normalize_price`](./3.%20Symbol_Math.md).
* **Respect stops level.** SL/TP closer than `trade_stops_level` is rejected (error 130).
* **Not retried.** On `MT4Error::TradeError` from a timeout, check [`positions`](./9.%20Order_Info.md) before resending.
