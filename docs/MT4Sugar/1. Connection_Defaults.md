# MT4Sugar — 1. Connection & Defaults

> Connect, disconnect, liveness, and the magic / slippage / comment applied to every order-entry helper.

`MT4Sugar::new(svc)` starts with `magic = 0`, `slippage = 20`, empty `comment`. Chain `.set_defaults(...)` to change them.

---

## `set_defaults(magic, slippage, comment)`

```rust
pub fn set_defaults(self, magic: i32, slippage: u32, comment: impl Into<String>) -> Self
```

Builder — sets the defaults the [Order Entry](./5.%20Order_Entry.md) helpers stamp onto each order. Returns `self`, so chain it after `new`.

```rust
use metarpc_mt4::{MT4Account, MT4Service, MT4Sugar};

let sugar = MT4Sugar::new(MT4Service::new(MT4Account::new("mt4.mrpc.pro", 443)))
    .set_defaults(1001, 20, "my-bot");   // magic 1001, 20-point slippage, comment "my-bot"
```

> `magic = 0` means "don't stamp a magic"; an empty comment means "don't stamp a comment".

---

## `connect_by_server_name(login, password, server, name, timeout_seconds)`

```rust
pub async fn connect_by_server_name(&self, login: u64, password: &str, server: &str,
    name: Option<&str>, timeout_seconds: u32) -> Result<(), MT4Error>
```

Resolve the broker by server name and log in. `name` is an optional terminal label; `timeout_seconds` bounds the connect.

```rust
sugar.connect_by_server_name(12_345_678, "password", "FreshForex-Demo", None, 120).await?;
```

---

## `reconnect()`

```rust
pub async fn reconnect(&self) -> Result<(), MT4Error>
```

Re-establish the session using the parameters from the last connect.

```rust
if !sugar.ping().await { sugar.reconnect().await?; }
```

---

## `disconnect(delete)`

```rust
pub async fn disconnect(&self, delete: bool) -> Result<(), MT4Error>
```

Close the session. `delete = true` also removes the terminal instance server-side; `false` leaves it for a quick reconnect.

```rust
sugar.disconnect(false).await?;
```

---

## `ping()`

```rust
pub async fn ping(&self) -> bool
```

Liveness probe — `true` if an `account_summary` round-trip succeeds. Never errors (any failure → `false`).

```rust
if sugar.ping().await { println!("alive"); }
```
