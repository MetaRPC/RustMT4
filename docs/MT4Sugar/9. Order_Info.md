# MT4Sugar — 9. Order Info

> Read the open book and account state — filtered views, lookups, P/L sums, exposure, and a compact account snapshot.

In MT4 an open **market** order *is* a position; pendings sit in the same list, told apart by `order_type` (0 Buy, 1 Sell = market; 2–5 = pending).

---

## `orders()`

```rust
pub async fn orders(&self) -> Result<Vec<pb::OpenedOrderInfo>, MT4Error>
```

All open **market + pending** orders (sorted by open time asc).

---

## `positions()`

```rust
pub async fn positions(&self) -> Result<Vec<pb::OpenedOrderInfo>, MT4Error>
```

Open **market** orders only — MT4's equivalent of "positions".

```rust
println!("{} positions open", sugar.positions().await?.len());
```

---

## `orders_for_symbol(symbol)` / `orders_by_magic(magic)`

```rust
pub async fn orders_for_symbol(&self, symbol: &str) -> Result<Vec<pb::OpenedOrderInfo>, MT4Error>
pub async fn orders_by_magic(&self, magic: i32) -> Result<Vec<pb::OpenedOrderInfo>, MT4Error>
```

Filtered views of the open book — by symbol, or by the EA magic number.

```rust
let mine = sugar.orders_by_magic(1001).await?;
```

---

## `find_ticket(ticket)`

```rust
pub async fn find_ticket(&self, ticket: u64) -> Result<Option<pb::OpenedOrderInfo>, MT4Error>
```

One open order by ticket, or `None` if it isn't open.

```rust
if let Some(o) = sugar.find_ticket(123_456).await? {
    println!("{} {:.2} lot  P/L {:+.2}", o.symbol, o.lots, o.profit);
}
```

---

## `total_profit(symbol)`

```rust
pub async fn total_profit(&self, symbol: Option<&str>) -> Result<f64, MT4Error>
```

Total floating profit across open positions (`profit + swap + commision`), optionally for one symbol.

```rust
println!("floating P/L: {:+.2}", sugar.total_profit(None).await?);
```

---

## `positions_value(symbol, magic)`

```rust
pub async fn positions_value(&self, symbol: Option<&str>, magic: Option<i32>) -> Result<f64, MT4Error>
```

Floating value of positions filtered by symbol **and/or** magic (`None` = don't filter on that axis). Includes swap and commission.

```rust
let v = sugar.positions_value(Some("EURUSD"), Some(1001)).await?;
```

---

## `exposure_summary()`

```rust
pub async fn exposure_summary(&self) -> Result<Vec<(String, f64)>, MT4Error>
```

Net lots per symbol across open market positions — **buy positive, sell negative**. Sorted by symbol.

```rust
for (sym, net) in sugar.exposure_summary().await? {
    println!("{sym}: net {net:+.2} lots");
}
```

---

## `get_account_info()`

```rust
pub async fn get_account_info(&self) -> Result<AccountInfo, MT4Error>
```

A compact [`AccountInfo`](https://github.com/MetaRPC/RustMT4/blob/main/src/models.rs) snapshot: `login`, `currency`, `balance`, `equity`, `credit`, `leverage`, `name`, `company`, `trade_mode`, `is_investor`, `server_time`, `utc_shift_minutes`.

```rust
let a = sugar.get_account_info().await?;
println!("{} {} — balance {:.2}", a.login, a.currency, a.balance);
```

> For margin / free-margin / margin-level, read the full `AccountSummaryData` via [`MT4Service::account_summary`](../MT4Service/1.%20Account_Information.md) — `AccountInfo` omits those.
