# MT4Sugar — 8. Watchers & Waiters

> **Watchers** wrap a gRPC stream into a `tokio::mpsc` channel of friendly values (a background task forwards frames). **Waiters** poll until a condition holds or a timeout elapses.

The background task of a watcher ends on the first stream error or when you drop the receiver.

---

## `subscribe_quotes(symbols)`

```rust
pub async fn subscribe_quotes(&self, symbols: Vec<String>) -> Result<mpsc::Receiver<Quote>, MT4Error>
```

Live ticks for `symbols`, delivered as [`Quote`](./2.%20Prices_Quotes.md)s.

```rust
let mut rx = sugar.subscribe_quotes(vec!["EURUSD".into(), "GBPUSD".into()]).await?;
while let Some(q) = rx.recv().await {
    println!("{:<8} {}/{}", q.symbol, q.bid, q.ask);
}
```

---

## `watch_profit(interval_ms)`

```rust
pub async fn watch_profit(&self, interval_ms: i32) -> Result<mpsc::Receiver<pb::OnOpenedOrdersProfitData>, MT4Error>
```

Per-order floating profit + account snapshot every `interval_ms`. Each item is the raw `OnOpenedOrdersProfitData` (`account_info.equity`, `account_info.profit`, `opened_orders_with_profit_updated`).

```rust
let mut rx = sugar.watch_profit(1000).await?;
while let Some(d) = rx.recv().await {
    if let Some(a) = d.account_info { println!("equity {:.2} floating {:+.2}", a.equity, a.profit); }
}
```

---

## `watch_tickets(interval_ms)`

```rust
pub async fn watch_tickets(&self, interval_ms: i32) -> Result<mpsc::Receiver<pb::OnOpenedOrdersTicketsData>, MT4Error>
```

The open-order ticket list every `interval_ms` (`position_tickets`, `pending_order_tickets`, pre-split).

```rust
let mut rx = sugar.watch_tickets(1000).await?;
while let Some(d) = rx.recv().await {
    println!("{} positions, {} pendings", d.position_tickets.len(), d.pending_order_tickets.len());
}
```

---

## `wait_price(symbol, target, above, timeout)`

```rust
pub async fn wait_price(&self, symbol: &str, target: f64, above: bool, timeout: Duration) -> Result<Quote, MT4Error>
```

Poll until the price reaches `target` — `above = true` waits for `bid ≥ target`, `false` for `ask ≤ target`. Returns the triggering [`Quote`], or errors on timeout.

```rust
use std::time::Duration;
let q = sugar.wait_price("EURUSD", 1.0900, true, Duration::from_secs(60)).await?;
println!("hit {} at bid {}", 1.0900, q.bid);
```

---

## `wait_filled(ticket, timeout)`

```rust
pub async fn wait_filled(&self, ticket: u64, timeout: Duration) -> Result<bool, MT4Error>
```

Poll until a pending `ticket` becomes a market order (filled). `true` on fill, `false` on timeout.

```rust
use std::time::Duration;
if sugar.wait_filled(123_457, Duration::from_secs(300)).await? {
    println!("pending filled");
}
```

---

## `wait_closed(ticket, timeout)`

```rust
pub async fn wait_closed(&self, ticket: u64, timeout: Duration) -> Result<bool, MT4Error>
```

Poll until `ticket` is no longer open (closed or deleted). `true` on close, `false` on timeout.

```rust
use std::time::Duration;
sugar.wait_closed(123_456, Duration::from_secs(120)).await?;
```

---

## ⚠️ Pitfalls

* **Watchers vs waiters.** Watchers push continuously (keep the receiver alive); waiters return once.
* **Waiters poll every 500 ms** — they're convenience, not low-latency triggers. For hot paths use `subscribe_quotes`.
* **Drop to unsubscribe.** Dropping the `Receiver` ends the watcher's background task.
